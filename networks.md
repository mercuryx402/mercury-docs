# Networks

Mercury settles on **Base mainnet** (USDC) today — the deepest x402 liquidity. x402 is *one protocol*
across many chains (a `network` field per payment), so Mercury expands to where the agents are, in
liquidity order. Same `/buy/*` endpoints and signed receipts on every chain.

| Network | Status |
|---|---|
| **Base** (mainnet, USDC) | ✅ live |
| Polygon · Arbitrum · Optimism · World · Avalanche | EVM siblings — same facilitator |
| **Solana** | next (the #2 x402 market) |
| XRP · Tron · Stellar · Bitcoin (Lightning / L402) | on demand |

You pay on whichever network your agent already lives on.
