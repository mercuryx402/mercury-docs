# FAQ

**Do I need a Mercury account or API key?** No. You bring a Base-mainnet wallet with USDC; that's it.

**What does it cost?** ~$0.003–$0.02 per call (see [catalog](catalog.md)). You pay per request; no plan.

**Which network?** Base mainnet (`eip155:8453`), real USDC. The asset is `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`.

**Can a human use it?** Yes (any x402 client), but it's built for agents — no signup means an agent can
onboard itself.

**Is the data trustworthy?** Every result is signed (see [Provenance receipts](provenance.md)) — you can
verify offline that the bytes are genuine.

**Open source?** The MCP server is: [github.com/0xjed/mercury-x402-mcp](https://github.com/0xjed/mercury-x402-mcp).
