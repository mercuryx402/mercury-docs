# Mercury

**Keyless, signed web data your AI agent pays for itself.**

Mercury is an agent-payable web-data network. An AI agent discovers a service, pays for it per call
over **x402** (Base mainnet, USDC), and gets back clean data **plus an EIP-191 provenance receipt** it
can verify offline — in about 5 lines of code. No API key, no account, no signup.

* **Keyless** — every other web-data API (Firecrawl, Jina, Tavily) gates behind a human-created API key
  and a credit card, so an autonomous agent can't onboard itself. Mercury lets it pay directly.
* **Signed** — every result ships a provenance receipt proving the bytes are genuine and untampered —
  what RAG, trading, and agent-to-agent commerce actually need.
* **Per-call** — ~$0.003–$0.02 per request on Base mainnet. Pay only when you call; browse for free.
