# Mercury

**Keyless, signed web data your AI agent pays for itself.**

Mercury is an agent-payable web-data network. An AI agent discovers a service, pays per call over
**x402** (Base mainnet, USDC) **or with a Mercury API key**, and gets back clean data **plus an EIP-191
provenance receipt** it can verify offline — in about 5 lines. No signup required.

* **Two rails** — bring a **wallet** (keyless x402) *or* a **free API key** ([get one](https://mercury-x402-jed.fly.dev/developers)): same endpoints, same signed receipts.
* **Keyless** — agents that hold a wallet onboard themselves; no human-made API key + credit card.
* **Signed** — every result ships a provenance receipt proving the bytes are genuine + untampered.
* **Per-call** — ~$0.003–$0.02 per request. Pay only when you call; browse for free.
