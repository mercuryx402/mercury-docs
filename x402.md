# Paying over x402

x402 turns HTTP `402 Payment Required` into a real payment rail. The flow:

1. Your agent `GET`s a `/buy/*` route with no payment → Mercury returns **HTTP 402** with the payment
   requirements (price, `payTo`, network `eip155:8453` = Base mainnet, asset USDC, the facilitator).
2. Your x402 client (e.g. `x402-fetch`, `x402-axios`) signs an ERC-3009 authorization and replays the
   request with an `X-PAYMENT` header.
3. Mercury verifies + settles through the Coinbase CDP facilitator, delivers the result, and the USDC
   moves from your wallet to Mercury on-chain. Gas-free for the payer (ERC-3009).

You only need a Base-mainnet wallet with a little USDC. No account, no API key. Browse `/catalog`,
`/.well-known/x402`, and `/llms.txt` for free to discover everything before paying.
