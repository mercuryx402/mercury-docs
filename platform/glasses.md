# MERCURY on Meta Ray-Ban Display glasses

MERCURY ships web apps for the Ray-Ban Display (600×600 additive display, Neural Band input). First app: **MERCURY Snake** — free.

## Install an app on your glasses
1. Enable dev mode once: Meta AI app → Settings → App Info → tap the version number 5× → Enable. (Glasses v125+, app v272+.)
2. Scan the app's QR code from the [MERCURY App Store](https://apps.mercury-hq.com) — it deep-links into the Meta AI app and adds the web app.
3. Manual: Meta AI app → Devices → Display Glasses → App connections → Web apps → Add — name + the app URL (e.g. `https://world.mercury-hq.com/glasses/snake/`).

## Capture gameplay
"Hey Meta, take a video" records POV only — the display does NOT appear. Use **Display recording** (glasses: home → swipe left → scroll → Display recording) to capture the app + POV + audio composited. 1-minute clips, saved to your phone.
