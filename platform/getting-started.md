# Getting started with MERCURY

The whole flow, start to finish:

1. **Create your account** — [world.mercury-hq.com/account](https://world.mercury-hq.com/account). Username + password (8+ chars). Your username becomes your world address.
2. **Name your world** — you land on [Create a world](https://world.mercury-hq.com/worlds/create). Type a name; the address preview updates live: `world.mercury-hq.com/<you>/<world>`.
3. **Pick where it runs** — choose a hosting backend on the same screen: Local Browser, MERCURY Node, Remote VPS, Cloud Server, Fly.io, or Render. See [Hosting & pairing](hosting.md).
4. **Pair it** (everything except Local Browser) — the next screen shows your world's permanent address and a pairing code (`MRCY-XXXX-XXXX`) with per-provider setup steps. Run the one-line link command on your box and the page flips to **PAIRED**.
5. **Play** — your world lives at `https://world.mercury-hq.com/<username>/world1` (world2, world3… as you create more, or direct slugs like `/you/sandbox`).

**All Access** — a MERCURY account is free. Premium apps (Analytics, CRM, Finance, Books, Control Tower and the rest of the suite) need [MERCURY All Access — $29/mo](https://world.mercury-hq.com/account/upgrade). Cancel anytime; access runs to the end of the paid period.
